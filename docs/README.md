# Candidate concepts and maturity

Bootstrap: `RESEARCHFABRIC-REAL-PROJECT-BOOTSTRAP-001` (2026-10-01). There is no implementation or adopted technical stack. The following is a research outline, not a normative specification.

| Candidate area | Open questions |
| --- | --- |
| Interface Grammar | Semantic vocabulary, state/interaction model, representation, and validation remain TBD. |
| Design Tokens | Token schema, typing, typography, layout, density, accessibility, motion, and animation remain TBD. |
| Platform Profiles | Capability profiles, cross-surface adaptation, and graceful degradation remain TBD. |
| Implementations | Web, Qt/QML, TUI, and Android are target surfaces; languages, frameworks, adapters, APIs, and support status remain unadopted. |

[cross-surface-interface-design-lab](https://github.com/JerrySkywalker/cross-surface-interface-design-lab) owns private research and evidence; this public repository owns product source. An explicit Owner decision is required before an adopted specification or implementation is introduced. Public documentation must state its actual implementation limits and must not disclose private research without clearance.
