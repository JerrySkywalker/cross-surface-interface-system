# Cross-Surface Interface System

An open-source cross-surface interface system for expressing coherent interface semantics across heterogeneous interaction surfaces.

Current maturity: conceptual documentation bootstrap. Web, Qt/QML, TUI, and Android are intended/target surfaces. No surface implementation, component library, package, renderer, or supported API exists yet. Concrete technology stacks and final architecture remain under research until explicitly adopted by the Owner.

## Candidate concepts

- **Interface Grammar** — a candidate language for shared interface meaning and interaction semantics.
- **Design Tokens** — candidate shared expressions of visual and interaction intent.
- **Platform Profiles** — candidate descriptions of capabilities, adaptation, and graceful degradation.
- **Implementations** — future surface mappings; none are implemented.

These concepts are candidate/TBD, not adopted specifications. See [concept and maturity notes](docs/README.md). No speculative framework directories are scaffolded.

Private research is not automatically public or cleared for reuse. [software-engineering-research-vault](https://github.com/JerrySkywalker/software-engineering-research-vault) provides private reviewed software knowledge context.

Research findings and an assistant recommendation do not adopt architecture. Implementation choices require an explicit Owner decision and public documentation of the adopted scope. Links are navigation only, with no automatic synchronization or template dependency.
