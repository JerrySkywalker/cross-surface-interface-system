# Contributing

The project is at documentation bootstrap stage. Review README, the candidate concept notes in `docs/`, and AGENTS before proposing a change. No implementation stack or surface API has been adopted.

Use a focused pull request explaining the problem, proposed behavior, and relevant verification. Clearly label candidates and unknowns. Do not scaffold speculative frameworks or imply supported surfaces. Architecture adoption remains an explicit Owner decision.

Review documentation links, factual claims, and `git diff --check` for documentation changes. There is no product build or test suite yet. Keep credentials, private evidence, generated output, and unrelated material out of contributions. Contributions are provided under the repository's MIT License.
